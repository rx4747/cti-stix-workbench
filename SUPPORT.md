# Support

Use [GitHub issues](https://github.com/rx4747/cti-stix-workbench/issues) for
reproducible bugs and focused feature requests. Include the plugin version,
Obsidian version, desktop platform, selected scope, diagnostic codes, and the
smallest sanitized fictional reproduction.

Do not attach an operational vault or sensitive Bundle. Security issues belong
in a private GitHub security advisory as described in [SECURITY.md](SECURITY.md).

The project is community-maintained. Response times are not guaranteed, and
support does not include intelligence analysis, incident response, or review of
real malware and restricted CTI.
